# DAA-Lab-Practicals

Collection of C++ programs for Design and Analysis of Algorithms (DAA) lab practicals — B.Tech CSE (AI/ML), Marwadi University.

## 📂 Practicals Index

| Practical | Topic | Algorithms Covered |
|-----------|-------|---------------------|
| 1 | Sorting | Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort |

## 📁 Folder Structure

DAA-Lab-Practicals/

    ├── bubble_sort.cpp
    ├── selection_sort.cpp
    ├── insertion_sort.cpp
    ├── merge_sort.cpp
    └── quick_sort.cpp

## 🧠 Algorithms — Time & Space Complexity

| Algorithm | Best Case | Average Case | Worst Case | Space Complexity |
|-----------|-----------|---------------|------------|-------------------|
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) |
| Selection Sort | O(n²) | O(n²) | O(n²) | O(1) |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n) |

## ▶️ How to Run

1. Clone the repository:
   git clone https://github.com/kishorereddycse860-hub/DAA-Lab-Practicals-.git

2. Navigate to the Sorting folder:
   cd DAA-Lab-Practicals-/Sorting

3. Compile any file using g++:
   g++ bubble_sort.cpp -o bubble_sort

4. Run the compiled program:
   ./bubble_sort

- **Language**: C++
- **Style**: Class-based OOP implementation
- **Compiler**: GCC / G++
